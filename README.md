# CS 499 Computer Science ePortfolio

Portfolio website for Gavin Elliott.

## View locally

Open `index.html` in a web browser. No build tool or dependencies are required.

## Publish with GitHub Pages

1. Create a GitHub repository named `cs499-portfolio` or another name of your choice.
2. Upload the contents of this folder to the repository root.
3. Open repository Settings, then Pages.
4. Select Deploy from a branch, choose the main branch and root folder, and save.
5. Wait for GitHub to provide the published site address.

## Before final submission

* Verify the embedded YouTube code review plays on the published website and that its visibility allows your instructor to view it.
* Read the drafted professional self assessment carefully and revise any wording that does not describe your own experience accurately.
* Check original and enhanced artifact downloads.
* Confirm that the portfolio link opens in an incognito browser.
* Submit the website URL and the course files required by your instructor.

## Included materials

* Full original milestone submissions under `artifacts/`.
* Individual original and enhanced artifact archives under `artifacts/`.
* Submitted Word narratives under `narratives/`, with readable versions included in the website.

This website is a static presentation of the attached completed coursework. It does not claim to execute the three applications in the browser.
